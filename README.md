# RailGo (fixed)

An accessible train-booking demo page. An AI agent rewrote it from a deliberately inaccessible original, as part of a ShareViewsWeek session on working with AI agents.

**RailGo is fictional.** No booking is made, no payment is taken, and no e-mail is sent.

Test task: book a one-way ticket from Warszawa Centralna to Kraków Główny on 14 November 2026, on the 09:10 departure, for 1 adult and 1 student, in seats 21 and 22 of carriage 3, with a bicycle and no travel insurance, for the lead passenger Ada Lovelace. Then note the confirmation code.

Live page: https://zenobia-gawlikowska.github.io/railgo-fixed/

## Versions
- `/` – the version first tested by hand (builder turn 3). Known issue: blocked with TalkBack on Android at the station picker.
- `/v2/` – builder turn 4: plain native station dropdowns, and no field is announced as invalid before the user continues. Live at https://zenobia-gawlikowska.github.io/railgo-fixed/v2/
